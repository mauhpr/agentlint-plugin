# Security Policy

## Supported Versions

Security fixes are provided for the latest AgentLint Plugin release. Issues in
the AgentLint Python package should be reported against the main AgentLint
repository.

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability or include secrets,
tokens, private source code, or exploit details in a public report.

Report vulnerabilities privately to **mauricio_perez_r@hotmail.com** with the
subject prefix `[SECURITY][AgentLint Plugin]`. Include the affected plugin and
AgentLint versions, potential impact, reproduction steps, and a minimal proof of
concept when possible.

Reports are acknowledged on a best-effort basis. We will coordinate disclosure
and credit reporters unless they prefer to remain anonymous.
